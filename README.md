# رفيق المسلم — تطبيق Android تجريبي (Kotlin)

مشروع Android أصلي باستخدام Kotlin وJetpack Compose. الواجهة عربية RTL وتضم تبويبات الرئيسية، مواقيت الصلاة، القرآن، الأذكار، والقبلة.

## فتح وبناء التطبيق

1. افتح مجلد المشروع في Android Studio حديث.
2. اسمح بمزامنة Gradle وتنزيل Android SDK Platform 35 عند الطلب.
3. شغّل تطبيق `app` على جهاز أو محاكي Android 8.0/API 26 أو أحدث.

من الطرفية بعد إعداد Android SDK:

```bash
./gradlew assembleDebug
```

## ما يعمل في النموذج

- حساب محلي لمواقيت الصلاة باستخدام مكتبة `adhan-kotlin`، بإحداثيات افتراضية لمكة.
- إدخال خط العرض والطول في شاشة الصلاة، وفهرس سور وقارئ نصي يتصلان بـ AlQuran Cloud عند فتح الشاشة.
- عدّاد أذكار محفوظ محليًا باستخدام SharedPreferences.
- حساب اتجاه القبلة من الإحداثيات الافتراضية، مع قراءة حساس الدوران إن توفر.
- تبديل فاتح/داكن وتنقل Compose.

## حدود مهمة قبل الإنتاج

هذا **نموذج MVP تجريبي** وليس إصدارًا نهائيًا للنشر. يجب مراجعة اختيار طرق الحساب: واجهة الطرق موجودة بينما محرك النموذج يستخدم أم القرى حاليًا. إحداثيات القبلة في هذا النموذج ثابتة وليست مرتبطة بإحداثيات الصلاة. لم تُنفّذ بعد أذونات GPS وطلب الموقع، تنبيهات الصلاة، تنزيل القرآن دون اتصال، التلاوات، الترجمة/التفسير، البحث في نص الآيات، مزامنة الحساب، الخرائط offline أو الاشتراكات. بيانات الأذكار المختارة تحتاج مراجعة وتخريجًا علميًا قبل النشر. قارئ القرآن يتطلب اتصالًا بالإنترنت ولا يخزن المحتوى محليًا؛ راجع شروط وترخيص API والمحتوى قبل التوزيع التجاري.

لا يحتوي المستودع على مفاتيح توقيع أو أسرار. راجع اعتماديات Gradle وسياسات Google Play، وأضف الاختبارات والمراجعة العلمية والأمنية قبل إطلاق عام.
